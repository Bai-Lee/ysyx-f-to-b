# 公开范围、脱敏和完整性

这是从原始 F～B 工程导出的独立公开快照，原私人源码、原交付包和历史证据未被修改。Git 便于浏览源码、任务原文和主要报告；Release 完整快照补充较大的历史文本输出、向量、网表与图示，解压后恢复相同相对目录。

## 已做的脱敏

- Windows 用户目录、本机工作区绝对路径、Linux 工作台用户路径、WSL 实例名称与主机名改成占位值。
- 使用全新 Git 历史，不推送原工作区的提交身份、远程配置、缓存、临时目录、浏览器资料或个人资格材料。
- 扫描了私钥、GitHub/API 令牌、带口令的 URL、凭据赋值与本机标识。私钥检测器中的字面字符串、测试样例和上游许可联系方式经区分处理。
- 最终 CPU RTL、网表和测试平台的核心输入保持原字节；路径或链接修改后的历史材料使用新的公开哈希。

这项检查不等于对所有潜在敏感信息作绝对保证。上游公开作者/许可证联系方式和课堂示例身份保留其原本用途。

## 文件去向与哈希

- `provenance.json`：原工程相对路径、原 SHA-256、公开相对路径和当前 SHA-256。修改不覆盖原始证据。
- `excluded.json`：未复制文件及原因，包含重复/编译归档、外部整库、原始书籍示例、工具缓存与本地配置等。
- `supplement.json`：Release 内提供、Git 正文未逐文件收录的大输出和图示。
- `FILES.sha256`：完整公开快照的字节哈希清单，不包含它自身。
- `verification.json` 和 `demo/`：本次新增便携仿真的三项实测。
- `b-soc-demo/`：发布前已实际运行的最终 B 完整 SoC 控制台短演示，包括 RT-Thread、上下文和 MicroBench；输入绑定见 summary.json。

历史报告里的哈希仍指原始私有文件，不应拿脱敏副本去伪装原字节匹配。部分报告链接已指向补充包或官方页面；未重新运行的长测试仍是历史记录。

## 大文件和依赖

原累积交付 ZIP 含大量重复阶段快照，并包含外部源码、已编译工具/程序及原目录信息，未直接上传。源码与可公开文本成果已尽量展开整理。第三方完整依赖、操作系统/工具安装和原始大二进制由上游来源恢复；本次不声称任意机器免依赖重现完整工程。

本次公开的是原工程的成果快照，不包含全部 `artifacts/` 长日志/波形，也不保留所有中间编译缓存。未收录的数据不会被写成已经公开。来源与许可见根目录 THIRD_PARTY.md。
