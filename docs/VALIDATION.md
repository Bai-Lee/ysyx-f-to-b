# 验证和性能数据应如何理解

历史工程报告来自原工作台的实际运行。本次发布仅对新增便携入口重做了小规模正反例；没有重新执行全部 F～B 长任务。公开副本中的环境路径已脱敏，原日志与原字节仍保留在私有完整交付中。

## B 阶段的主要实测范围

- 最终完整 SoC：35 个原始 CPU 正例和原始 wrong.c 反例；1200 条确定性随机算术/访存操作及独立整数模型期望。
- NEMU：逐条退休指令进入比较或明确记录的 MMIO 同步。MMIO 独立检查后同步参考状态，不代表两个独立设备模型。
- OS：RT-Thread 启动、脚本命令及同步上下文切换；未证明异步抢占。
- 内存：八个独立图样各自完整写入并读回 128 MiB；累计 28,850,962,770 周期和 2,936,031,090 条退休指令。
- 四值：RTL/最终门级完整程序；标准单元模型检查和故意错误模型对照；没有 SDF。
- 等价：导出规范化的 5,248 个等价点通过，范围是配对状态下的导出等价。
- 可选流水线形式化 miter：600 秒 TIMEOUT，既不是证明通过，也不是反例。

入口：[B 总报告](../reports/B_REPORT.md)、[B5 验收](../reports/B5_ACCEPTANCE.json)、[全容量结果](../reports/B4_full128.json)、[配置与哈希](../reports/B_final_selection.json)。

## 模型性能

| 完整 SoC 配置 | train 周期 | 使用频率 | 模型时间 |
|---|---:|---:|---:|
| 最终流水线 | 1,575,356,367 | 325 MHz | 4,847.250 ms |
| 无缓存校准基线 | 6,602,359,659 | 400 MHz | 16,505.899 ms |
| 历史多周期缓存 | 1,806,294,567 | 400 MHz | 4,515.736 ms |

模型时间按周期/频率计算。最终方案相对无缓存校准基线约快 3.405 倍，但比表中历史多周期缓存慢约 7.34%。最终选择只在已测试的指定候选中成立。最终 train 当次主机耗时 2,174.52 秒，不能把它与 4.847 秒的模型时间混为一谈。

## 模型面积与时序

CPU 含 icache 和内部接口，Nangate45 教学库单元面积 24,878.182 μm²，选定 325 MHz 模型点；APB/AXI Q8 延迟比均为 832。建立/保持与最大转换时间检查有记录，最大电容没有通过结论。

B 没有布局、布线、提取寄生、多角、电源签核或制造/硅后测量。早期 E8 候选的 50 MHz 物理流程数据属于另一设计；公开其版图图片是历史过程展示，不能据此断言 B 已流片。
